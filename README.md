# JAVA-practice
今天吃什么--校园美食决策助手
## 主要功能:
- 1.自己添加食堂、档口、菜品。
- 2.上传菜品照片，记录价格。
- 3.给菜品打分:味道、价格、分量、推荐程度。
- 4.收藏、踩雷、吃过记录。
- 5.按预算、口味、类别筛选。
- 6.今日吃什么随机推荐。
- 7.自动生成个人美食排行榜。
- 8.统计每个月的饮食消费。

## 页面介绍
| 页面 | 负责的功能 |
|---|---|
| **首页** | 浏览食堂、档口和菜品；按预算、口味、类别筛选；“今日吃什么”随机推荐；添加入口 |
| **记录** | 用“吃过 / 收藏 / 踩雷”切换列表；查看吃饭日期、实付金额、评分和评价；快速记一餐 |
| **我的** | 自动生成个人美食排行榜；查看每月消费、用餐次数、平均每餐花费；管理食堂和档口 |
