# 第一阶段验证记录

验证日期：2026-11-23。环境：Windows、JDK 27.0.1.0.2、项目内 Maven 3.9.9。

执行命令：`./build.ps1 test`。结果：**10 项集成测试通过，0 失败、0 错误、0 跳过**。
测试使用真实 Spring Boot 服务、随机 HTTP 端口、独立 H2 内存数据库及临时照片目录。

| 场景 | 主要验证 |
| --- | --- |
| 一餐多菜及历史快照 | 实付相加，按餐计次；菜品涨价、改名不改写历史 |
| 多次评分与榜单 | 平均评分正确；未评分不算零分；删除记录立即更新 |
| 事务回滚 | 部分无效菜品、同餐重复菜品不会留下半餐数据；失败修改不损坏原记录 |
| 筛选及推荐 | 预算和口味匹配，踩雷与归档被排除，无候选有明确反馈 |
| 用户归属 | 另一用户无法读取或标记他人菜单、用餐、照片，统计与榜单隔离 |
| 照片生命周期 | 真实 PNG 上传、读取和删除；伪装图片拒绝 |
| 月份边界 | 下月零点不计入上月；空月份不发生除零 |
| HTTP 参数和状态 | JSON 错误、空名称、非法分页、月份、排序、重复名称与资源不存在 |
| HTTP 用餐流程 | 实际请求创建评分记录并查询榜单、消费；拒绝超范围评分和负金额 |
| 短时间并发查询 | 8 个工作线程发起 32 次请求，全部返回 200 |

原始报告由 Maven 生成在 `target/surefire-reports/`。这是一轮核心可靠性验证，不代表生产环境压力测试或完整的多人身份认证测试。
